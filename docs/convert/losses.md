# 有损转换

页面固定列出每个来源可能无法无损转换的内容，并逐项注明原因。下表按来源汇总类别；具体条目以 `src/lib/formats/<id>.js` 的 `losses` 字段为准，页面上的表格直接读取它。

## Altium

PCB：

- **层数上限**：最多 10 层铜层，层数更多的板直接转换失败。
- **设计规则**：只导出全局最小线宽与过孔尺寸，间距、差分对、规则优先级、网络类、Room、层叠材料不导出。
- **敷铜**：以 zone 输出，填充算法与优先级重算，需在 KiCad 重新灌注。
- **封装与库**：按焊盘几何重建，不引用封装库；库名、封装名不保留。
- **3D 模型**：STEP 与嵌入式模型不写入，需手动重新指定。
- **文字与丝印**：换成 KiCad 字体，字号、对齐、旋转有细微偏差。
- **其他标注**：尺寸标注、钻孔表、Gerber/装配输出设置、板级变体不导出。

原理图：

- **符号图形**：重建为通用符号或“方框 + 引脚”，厂商图形、引脚长度与样式被简化。
- **层次结构**：多张 `.SchDoc` 输出根图 + 子图，但根图没有图纸引脚；总线不导出。
- **设计数据**：ERC 标记、掩膜、参数集、设计变体、PCB 注释不导出。
- **文字与图形**：字体、字号、颜色、线宽按近似值输出，注释框和图片可能丢失。
- **封装与库**：封装映射只保留名称，符号与封装的绑定需在 KiCad 重新确认。

## Specctra

- **走线**：DSN 的 wiring 段若为空则只有布局与网表；自动布线结果需另传同一工程的 `.ses`。
- **设计规则**：`rule` / `clearance` 段（默认线宽、间距）不导出，需在 KiCad 重设。
- **层与图形**：内层走线与焊盘会落到 top/bottom；没有丝印、阻焊/助焊层图形和铜皮。
- **焊盘**：只按 circle/rect 重建；polygon/path 焊盘被简化，焊盘叠层不保留。

## EAGLE

PCB：

- **板框**：只导出 Dimension 层 wire 组成的主板框；`curve` 圆弧按直线弦处理。
- **设计规则**：规则、网络类、层叠材料、盲埋孔定义不导出；过孔只按 extent 还原起止层。
- **敷铜**：以 zone 输出，隔离带与灌注参数重算。
- **焊盘**：热焊盘/反焊盘与自定义焊盘简化，仅支持方、圆、椭圆；八角焊盘按方形输出。
- **封装与库**：元件的 attribute 与 3D 数据不导出；封装 Value 由元件值回填，封装库/封装名不保留。
- **文字与丝印**：丝印按直线与文字重建，矢量字体替换为 KiCad 字体。
- **其他标注**：Document(48) 等非丝印层说明文字不导出，避免工艺备注印上板。

原理图：

- **符号图形**：按库中线条、圆、多边形重建；引脚名不导出，名称与编号默认隐藏。
- **层次结构**：多张图纸输出为独立子图，同名网络按全局标签合并；模块不导出。
- **网络标签**：只来自 EAGLE 的 label，自动显示的 N$ 网络名不额外生成标签。
- **文字与图形**：图纸边框、标题栏与 plain 图形不导出；矢量字体与 designator 样式不保留。
- **封装与库**：元件属性不保留；原理图符号的 Footprint 由元件值推导。

## PADS

- **输入范围**：只读 ASCII `.asc`；二进制 `.pcb` 与 PADS Logic 原理图不支持。
- **敷铜**：内层铜箔按 net/面积输出为 zone，隔离带与热焊盘参数重算。
- **焊盘**：热焊盘（RT/ST）、反焊盘（RA/SA）、环形焊盘（A）不输出；叠层只取元件面那一层。
- **内层**：`-1` 层焊盘与走线缺少单层信息，会落到最近铜层或被跳过。
- **走线**：只在同层相邻线段间成对连线；弧线走线按直线段输出，圆弧板框按折线近似。
- **设计数据**：设计规则、网络类、层叠材料、盲埋孔、装配/阻焊/助焊层图形与文本不导出。
- **封装与库**：元件属性与 3D 模型不导出；封装名会保留。
- **文字与丝印**：用 KiCad 字体重排，矢量字体、字宽比例与对齐方式有偏差。

## 通用

转换完成后请在 KiCad 里逐项核对，重新灌注敷铜、补 3D 模型与设计规则，再导出制造文件。
